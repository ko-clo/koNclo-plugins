# DB 연결 설정

사용자는 **비개발자**다. 전문 용어를 쓰지 말고, 한 번에 한 가지만 물어본다.
**사용자에게 `pip` 같은 명령을 치게 하지 않는다 — 네가 직접 실행한다.**

## 1단계 — 이미 연결돼 있는지 먼저 확인

```bash
konclo-db-setup --check
```

- **성공(`✅ 연결 성공`)** → "이미 연결돼 있습니다. 바로 물어보셔도 됩니다."라고 알리고,
  4단계의 예시를 보여준 뒤 **끝낸다**. 다시 설정하겠다고 하면 3단계로 간다.
- **`command not found`** → 2단계(설치)로 간다.
- **그 밖의 실패** → 3단계(접속정보 등록)로 간다.

## 2단계 — 명령을 찾지 못할 때만 설치

"조회 통로를 먼저 설치하겠습니다. 30초쯤 걸립니다."라고 한 줄 알리고 진행한다.

### 2-1. 플러그인 폴더 찾기

`${CLAUDE_PLUGIN_ROOT}` 가 있으면 그것을 쓴다(Claude Code).
비어 있으면(Codex 등) 이 스킬 파일의 상위로 올라가 **`pyproject.toml` 이 있는 폴더**를 찾는다.

### 2-2. 설치

```bash
pip install "<플러그인 루트>"
```

실패하면 아래 순서로 다시 시도한다:

1. `python -m pip install "<플러그인 루트>"`
2. `py -m pip install "<플러그인 루트>"`
3. `python3 -m pip install "<플러그인 루트>"`
4. 권한 오류(`Permission denied` · `externally-managed-environment`)면 `--user` 를 붙여 재시도

넷 다 실패하면 **파이썬이 설치돼 있지 않은 것**이다. "이 PC 에 파이썬이 없어 개발팀 도움이
필요합니다"라고 안내하고 **멈춘다** (pip 오류 원문을 그대로 붙여 넣지 않는다).

## 3단계 — 접속정보 등록

비밀번호가 대화 기록에 남지 않는 방법을 **먼저 권한다**:

> 터미널에 `konclo-db-setup` 을 입력해 주세요. DB 이름·아이디·비밀번호를 차례로 물어보고,
> 비밀번호는 입력해도 화면에 보이지 않습니다.
> (Claude Code 안에서는 프롬프트에 `!konclo-db-setup` 이라고 입력하시면 됩니다.)

사용자가 "그냥 네가 해줘"라고 하면, DB 이름·아이디·비밀번호를 물어본 뒤 아래처럼 실행한다.
이 경우 **비밀번호가 대화에 남는다는 점을 한 줄로 미리 알린다.**

```bash
printf '%s' '<비밀번호>' | konclo-db-setup --dbname '<DB이름>' --user '<아이디>' --password-stdin
```

서버 주소·포트는 플러그인에 기본값이 들어 있으므로 **묻지 않는다.** 다른 서버를 봐야 한다고
사용자가 먼저 말하면 그때만 `--host` · `--port` 를 붙인다.

## 4단계 — 마무리 안내

설치를 새로 했다면 **Claude / Codex 를 껐다 켜야** 조회 도구가 잡힌다는 점을 알린다.
그리고 이렇게 물어보면 된다고 예시를 보여 준다:

- "이번 달 매장별 매출 보여줘"
- "지난달에 제일 많이 팔린 상품 20개 뽑아줘"
- "삼산이랑 서면 매출 비교해줘"
- "이거 엑셀로 저장해줘"

## 실패 시 안내 문구

| 증상 | 사용자에게 할 말 |
|---|---|
| 아이디/비밀번호 오류 | "아이디나 비밀번호가 맞지 않습니다. 개발팀에서 받은 값을 다시 확인해 주세요." |
| 연결 시간 초과 | "회사망(Tailscale)이 켜져 있는지 확인해 주세요." |
| DB 이름 오류 | "그런 이름의 DB 가 없습니다. DB 이름을 다시 확인해 주세요." |

**비밀번호는 어떤 경우에도 화면에 다시 출력하지 않는다.**
