# 베스트상품 에이전트 피드백 누적

> 3개 베스트상품 서브에이전트 공통 피드백 파일. 사용자가 "이거 이상해 / 이렇게 해야지 / 왜 그래 / 다시 / 안 맞는다" 류 지적 시
> 아래에 **F번호를 증가시켜 추가**한다. 형식·절차는 [[에이전트 공통 KERNEL]] §1.
> **삭제 금지**(역사 보존). 5건 누적 시 패턴을 [[베스트상품 대시보드 도메인 규칙]]에 흡수.

## 기록 형식

```
## F{번호} — 한 줄 요약  [서브탭: integrated|ka-tb|volume|공통]
- **상황**: 무엇을 하다가
- **지시**: 사용자가 무엇을 요구했는가
- **교훈**: 일반화된 규칙
- **적용방법**: 다음부터 어떻게 행동할 것인가
```
