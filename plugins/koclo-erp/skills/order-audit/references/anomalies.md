## 알려진 이상 패턴 (검수 체크리스트)

> 새 패턴 발견 시 아래 표에 즉시 추가. (이 스킬은 "계속 변경·추가" 전제)

| 증상 | 원인 | 확인 방법 / 판정 |
|---|---|---|
| **잘 팔리는데 주문 1장** (예: 레시피반팔 스카이 2w17·현재고12 → 1) | 안전재고 (17~20)=13 이 실판매보다 낮음 + 점수가 그 매장 상위5% 컷오프 미달 → 강화 미적용 | `explain` 로 `안전재고−현재고=기본주문`, `점수<gc` 확인. **산식대로면 버그 아님 = 정책 이슈** |
| **같은 품목인데 산출물마다 수량 다름** (노랑 2 vs 5) | 상위5% 컷오프 `gc`가 후보 모집단 의존 상대 백분위 → 모집단 다르면 경계 점수 품목의 강화 on/off 뒤집힘 | `compare` 로 두 산출물 `gc` 비교. **`gc` 상이 + 경계점수면 이게 원인** |
| 수량=0 행이 과반 | `통과(재고ok)`·`재고충분` 행이 .xls 에 포함됨(설계). 주문 아님 | `scan` 의 `수량0 NN%`. 주문 행만 보려면 비고 `주문/통과주문/강화` |
| 강화 태그인데 점수<컷오프 | 산출 시점 모집단과 표시 불일치 가능 | `scan` 의 `강화태그<컷오프` 플래그 |
| 사입처/품명 공백 | 정규화(pm_suppliers) `supplier_id` NULL/미매칭 → `s.name=''` (현재 시스템) | `scan` 의 `사입처공백`. DB 매칭 추적 필요 |
| 중복행 | 미송 병합/추출 중복 | `scan` 의 `중복행` |
| **베스트/급상승인데 안전재고만큼만 주문** (예: 타이레이어드셔츠 연회 1주판매8·재고4 → 2) | ① 안전재고는 *2주누계* 기준이라 급상승(전량 최근1주) 반영 못함(2w8→안전재고6). ② **베스트(KA/TB) 면제는 과락만 우회·수량은 안전재고−현재고로 제한**. ③ 2주판매분까지 채우는 상위5% 강화는 점수<gc로 미적용 | `explain` 통과주문(베스트)+`max(0,안전재고−현재고)` 확인. **안전재고<실판매 + 강화컷오프 미달 정책 이슈** (베스트 면제로도 수량 안 늘어남) |
| **최근입고 30일+ 인데 주문됨** (예: 비비PT 백메란지 입고5.18·36일 → 2) | 악성재고(`DEAD_STOCK_DAYS=30`)지만 **창고복귀 급상승 오버라이드**(line1527)로 컷 해제. C1=`2주전주간≥2 & 1주≥3 & 1주≥2주전×2`, C2=`2주전주간=0 & 1주≥4`(무판매→급등). 해제 후 안전재고−현재고로 정상 주문 | DB로 `sales_daily` 주별 분포 확인(s1w, s2w_prev). C1/C2 충족 시 **의도된 동작(다시 팔리는 상품 보충), 버그 아님** |
| **신상(오늘 입고)인데 과락** (예: 더블포켓다잉반팔티 그레이 2w1·점수25 → 0) | 신상 면제는 `is_new = 최초사입일경과일 ≤ 21`. **사입(purchase_daily) 기록이 0건**이면 `first_purchase_date=None → first_age_days=999(else 기본값)` → is_new=False 로 *무이력을 헌상품(999일)으로 뒤집음*. 판매만 있어 후보엔 들지만 점수 콜드스타트 바닥 → 하위30% 과락. 악성재고 과락엔 `last_purchase_date is None → 면제`(F19 line1521) 가드가 있으나 **점수 과락엔 그 가드가 없음** | DB 대조: `purchase_daily` 해당 product_id 사입 0건 + `sales_daily` 판매만 있음 확인. 입고가 아직 미인입(파이프라인 비대칭)이거나 product 신규생성만 된 상태. **신상 판정이 사입기록 의존 → 입고 미인입 시 신상보호 전부 무력화 = 로직 갭(정책+파이프라인)** |
