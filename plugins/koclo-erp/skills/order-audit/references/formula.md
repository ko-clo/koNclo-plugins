## 주문수량 산식 (검수 기준)

`order_v8_2_rebuild_FULL.py` + `auto_order_db.py` 의 확정 로직. 검수 스크립트 상수와 일치해야 함.

1. **기본 주문량** = `max(0, 안전재고(2주판매 구간) − 현재고)`
   - 안전재고 테이블(구간 → 안전재고): `(11~16)→8`, `(17~20)→13`, `(21~24)→18`, `(25~49)→22` …
   - 50+ 구간은 `min_stock` 미달 시에만 주문, 최대 `HIGH_SALES_ORDER_CAP=35`.
2. **상위5% 강화**: `점수 ≥ gc` 인 항목만. `gc` = **그 산출물 후보(점수>0) 점수의 95백분위** (동적).
   - 강화수량: 2w≤20 → 2주판매분까지 채움(`max(0, 2w−현재고)`), 21~29 → 80%, 30~49 → 75% (재고 게이트 60%).
   - 최종 수량 = `max(기본 주문량, 강화수량)`.
3. **과락(주문 0)**: 악성재고(30일+) / 점수 하위 30% / 조건부 LR.
4. **면제(베스트·샘플·신상)**: 과락 우회, 재고 부족분만 주문.
