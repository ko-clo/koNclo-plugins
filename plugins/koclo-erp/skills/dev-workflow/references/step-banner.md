### 카테고리 바 — ③ 설계·④ 승인 본문 안의 항목 구분

③·④ 는 한 스텝 안에 항목이 여럿(조사 요약·구현 방향·Trade-off …)이라 `라벨:` 만 두면 한 덩어리로 읽힌다.
항목마다 **카테고리 바** 한 줄을 머리로 단다.

```
━━ ❶ 조사 요약 ━━━━━━━━━━━━━━━━━━━━
```

- 스텝 경계는 `---`, 항목 경계는 `━━` — **모양을 섞지 않는다.** 항목에 `---` 를 쓰면 스텝 경계와 구분되지 않는다.
- 항목 번호는 `❶ ❷ ❸ …` 를 쓴다. 스텝 번호 `① ② ③` 과 겹치지 않게 한다.
- 바 앞에는 빈 줄을 두고, 내용은 바 바로 아랫줄부터 적는다. 꼬리 `━` 는 20개로 고정한다(길이를 맞추지 않는다).
- ③ 은 설계 에이전트 산출 항목 순서대로, ④ 는 §3 템플릿대로 단다.
  에이전트 결과를 `### 1.` 헤딩째로 relay 하지 않는다 — 스텝 헤딩(`###`)과 같은 급이라 스텝이 여러 개로 보인다.
- 적용 대상은 ③·④ 다.
