# ingest-guard — 적용 절차 체크리스트 (§3)

> 본체 `SKILL.md` 에서 분리. 새 인입 경로에 붙일 때에 읽는다.

## 3. 새 인입 경로에 적용하는 절차 (체크리스트)

대상 파서(예: `ingest_xxx.py`)에 방어로직을 붙일 때:

1. **파서가 읽는 필드를 전부 적는다.** 무엇을 읽는지(키/이름/가격/수량/날짜)와 그 **라벨**,
   반복 그룹의 폭과 라벨 순서. → 이게 필드 정의의 근거다. 위치(인덱스)는 라벨 행이 없는
   예외 파일용 폴백으로만 적어 둔다(`WIDE_PRODUCT_FIELDS` 의 두 번째 값).
2. **정본 양식의 ground-truth 를 실제 파일로 확보한다.** 실제 파일 1개를 열어 헤더/서브헤더/데이터
   첫 행을 찍어 라벨 위치를 확정한다(추측 금지). 빈 파일·소량 파일 변종도 확인.
3. **검증기 함수를 만든다** — `ingest_format_validator.py` 의 `validate_csv_wide` 를 본떠
   `(ok, problems, profile)` 를 반환. 필드 라벨 dict + 그룹 라벨/개수 **구조만**(데이터타입 검사는 넣지 않음).
   라벨 행 위치는 '헤더(빈 파일)' / '서브헤더(데이터 파일)' 양쪽을 모두 판별(`label_row_wide` 패턴).
   컬럼 해석은 **검증기와 파서가 같은 정본 함수**(`resolve_wide_product_cols`)를 호출한다 —
   각자 위치를 판단하면 둘이 갈려 '검증은 통과, 인입은 엉뚱한 컬럼'이 된다.
4. **가드를 연결한다** — 파서 진입부(데이터 로드 직후·행 루프/DB쓰기 이전)에서
   `_guard_format(validate_fn, ...)` 호출. 실패 시 raise.
5. **호출부를 처리한다** — 배치 루프는 `except FormatValidationError` 로 스킵+미마킹+`[FORMAT][SKIP]`
   로깅. 단일 실행은 메시지+exit 1. `--check` 서브커맨드 추가.
6. **테스트를 추가한다** — 정상 + 불량(컬럼삽입 시프트/컬럼수 오류/외래양식/빈파일) +
   **성능(데이터행 미순회)**. pytest 없이 도는 독립 실행 스크립트로 짠다. **테스트 파일은 커밋하지 않는다** —
   scratchpad 에서 돌리고 결과만 보고한다(`CLAUDE.md` §테스트 파일 커밋 금지).
7. **실데이터 전수 점검** — 운영 폴더의 동종 파일 전부에 `--check` 를 돌려 **false-positive 0** 확인.
   (macOS 한글 파일명은 NFD → `unicodedata.normalize('NFC', name)` 후 매칭.)
