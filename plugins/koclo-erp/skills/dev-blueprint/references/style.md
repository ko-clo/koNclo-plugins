# dev-blueprint — KO&CLO 스타일 정본 (§4-7) · UI 보존 (§4-8)

> 본체 `SKILL.md` §1 "스타일 정본"·"UI 보존" 의 상세다. 정본 없이 새로 만드는 탭은 §4-7, 정본을 옮기는 이관 탭의 콘텐츠 영역은 §4-8.

### 4-7. KO&CLO 스타일 정본 — 색·글꼴·컴포넌트 (MUST)

> 아래 값은 **발명한 것이 아니라** `frontend/css/*.css` 22개 파일의 **실사용 빈도에서 추출**했다.
> 토큰 정의 = `frontend/css/theme.css` 최상단 `:root`. 새 탭은 `var(--koclo-*)` 를 쓴다.

#### 색 토큰

정의와 값·용도 주석은 `frontend/css/theme.css` 최상단 `:root` 에 있다. 거기를 읽는다 — 여기에 값을 복사해 두지 않는다.

**accent 와 danger 를 구분한다.** `--koclo-accent` 는 브랜드이자 주액션(저장·설치 버튼)이다.
오류에까지 같은 빨강을 쓰면 **"눌러야 할 것"과 "잘못된 것"이 구분되지 않는다.**
`--koclo-danger` 값 자체는 여러 탭이 이미 쓰던 색이고, 새로 정한 건 **둘을 나눈다는 규칙 하나**다.

#### 글꼴 — 3종이 전부다

`index.html` 이 로드하는 것만 쓸 수 있다. 넷째를 선언하면 **로드되지 않아 OS 기본 글꼴로 떨어진다.**

| 토큰 | 값 | 용도 |
|---|---|---|
| `--koclo-font-sans` | `'DM Sans', sans-serif` | 본문 전부 |
| `--koclo-font-serif` | `'Instrument Serif', serif` | 페이지 제목·KPI 수치 |
| `--koclo-font-mono` | `'JetBrains Mono', monospace` | 코드·수치·날짜 |

> **실제 사고**: 디자인 프로세스 탭이 `IBM Plex Sans KR`·`IBM Plex Mono`·`Noto Serif KR` 를
> **43개 선언**에서 참조했는데 셋 다 미로드라 전부 시스템 글꼴로 렌더됐다.
> 새 글꼴이 꼭 필요하면 `index.html` 의 `fonts.googleapis.com` 링크에 **먼저 추가**하고 이유를 밝힌다.
>
> 그 셋은 2026-09-10 에 `index.html` 에 로드됐다 — 그 탭이 가안을 그대로 보존하는 **§4-8 예외**라서다.
> 로드돼 있다고 신규 탭이 써도 되는 것은 아니다. 신규 탭의 글꼴은 여전히 위 토큰 3종뿐이다.

크기 주력은 **12 · 11 · 13px**(빈도 62/48/41). 10px 은 표 헤더·캡션, 제목 `.page-title` 20px(serif), KPI 30px(serif).
모서리는 `--koclo-radius-lg 8px` / `-md 6px` / `-sm 4px`. 버튼 패딩 `7px 14px`, 표 셀 `10px 14px`.

#### 하지 않을 것

- **다크모드를 만들지 않는다.** 앱에 다크 테마가 없다(`theme.css` 의 `prefers-color-scheme` 0건).
  한 탭만 뒤집히면 그 탭만 튄다 — 실제로 디자인 프로세스 탭이 유일하게 그랬다.
- 파랑·보라(`#1565C0`·`#6A1B9A`)를 강조색으로 쓰지 않는다. 구 탭 잔재이지 정본이 아니다.
- 토큰에 없는 hex 를 새로 만들지 않는다. 필요하면 `frontend/css/theme.css` `:root` 에 먼저 추가한다.
- **데스크톱 화면이다.** 좁은 고정 폭(`max-width:520px` 류)을 쓰지 않는다(관행 `1600px` 내외 + `margin:0 auto`).
  `position:fixed` 요소(FAB·하단탭바·바텀시트)는 탭 DOM 밖 전체 뷰포트에 떠서 앱 크롬을 덮는다 — 쓰지 않는다.
  모바일이 필요하면 데스크톱 뷰를 고치지 말고 전용 뷰를 만든다(`mobile-blueprint`).

#### 공용 컴포넌트 — 새로 만들지 말고 재사용

`theme.css` 에 이미 있다. 같은 것을 탭 CSS 에 다시 정의하지 않는다.

| 클래스 | 정의 |
|---|---|
| `.loading-box` + `.spinner` | 로딩 표시(§4-5 — 필수) |
| `.page-title` | `Instrument Serif` 20px `#1A1A1A` |
| `.page-body` | `padding:20px 24px; flex:1; overflow-y:auto` |
| `.view-toolbar` | `padding:8px 24px`, 우측정렬, 흰 바탕, 아래 `1px solid #E8E6E3` |
| `.tbl` | th `10px` uppercase `#F5F5F3` / td `13px` / `.mono` = JetBrains Mono 12px |

#### 적용 범위

- **신규 탭·새로 쓰는 규칙**: 그대로 따른다.
- **기존 22개 CSS 의 hex**: 일괄 치환하지 않는다(전 탭 회귀 위험 대비 이득이 적다).
  그 파일을 어차피 손볼 때 **해당 규칙만** 토큰으로 바꾼다.
- 토큰 정의는 순수 추가라 **정의만으로는 어떤 화면도 바뀌지 않는다.**
- **정본 UI 를 옮기는 이관 탭의 콘텐츠 영역**: 이 절이 아니라 **§4-8** 을 따른다.

토큰 밖 hex·토큰 밖 글꼴·미로드 글꼴은 `scripts/check_blueprint.py` 가 `theme.css`·`index.html` 을 읽어 판정한다.
OS 에 깔린 시스템 글꼴(`-apple-system`·`Malgun Gothic` 등)은 로드가 필요 없으므로 "미로드"가 아니라 "토큰 밖"으로 센다.

### 4-8. UI 보존 — 정본을 옮기는 이관 탭 (MUST)

> **이관은 데이터소스 현대화이지 리디자인이 아니다.** iframe(baked-HTML)·가안처럼 **이미 승인된 화면(정본)** 을
> Vue 로 옮길 때는 그 화면을 시각적으로 동일하게 재현한다. 새 디자인을 만들지 않는다.

**경계 — 어디에 무엇이 적용되나**

| 영역 | 따르는 것 |
|---|---|
| 콘텐츠 영역(정본이 그리던 본문) | 정본 `<style>` 의 색·글꼴·간격과 정본 HTML 의 마크업 구조 **그대로**. 어두운 ERP 셸과 안 어울려 보여도 바꾸지 않는다 |
| 셸 크롬(빌드이력 바·탭바·새로고침 라인) | §4-7 KO&CLO 스타일 정본 |
| 정본 없이 새로 만드는 탭 | §4-7 전부. 이 절은 해당 없음 |

**절차**

1. CSS 를 쓰기 전에 정본 `<style>` 블록을 통째로 읽는다 — 서버 생성기면 `grep -n "<style>" <정본>.py`
   (`generate_*_report.py` · `rebuild_*_db.py` 의 `generate_html`), 가안이면 그 HTML.
2. 클래스→클래스 1:1 매핑표를 만들고 **값을 복사한다.** 변환은 `.<feature>` 루트 스코핑 하나뿐이다.
   색 토큰 치환·글꼴 교체·여백 조정을 하지 않는다. 동적 값(밴딩 색상 등)만 인라인.
3. 정본에 없는 규칙(ERP 셸과의 접합)은 파일 끝 **한 블록**에만 둔다. 정본이 갱신되면 위쪽을 재생성하고 그 블록만 얹는다.
4. CSS 머리 주석에 위 경계를 적는다. **"정본을 보존했다"는 서술은 정본 파일을 열어 대조한 뒤에만 쓴다** —
   근거 없는 보존 주장은 위반을 가린다.
5. 정본이 쓰는 글꼴이 미로드면 `index.html` 링크에 먼저 추가한다(본문 글꼴이 다르면 카드 폭·줄바꿈이 전부 어긋난다).

**보존하지 않는 것**: 다크모드 블록(앱에 다크 테마가 없어 그 탭만 뒤집힌다) · 프로토타입 전용 배너.
정본 자체의 버그는 고치되 무엇을 왜 고쳤는지 커밋에 남긴다.

**게이트**: `check_blueprint.py <feature> --preserve-ui` 로 돌린다. 토큰 밖 hex·토큰 밖 글꼴·`position:fixed` 가
FAIL 대신 **WARN** 이 된다 — 막지 않는 대신 그 목록이 **정본 값과 대조할 대상**이다. 미로드 글꼴·다크모드는 그대로 FAIL.

**`--preserve-ui` 는 위 절차 1~2 를 실제로 했을 때만 쓴다.** 정본이 없는 새 탭에 쓰거나, 정본을 열어 대조하지 않고 쓰면
그 자체가 아래 사고와 같은 위반이다 — WARN 으로 낮춘 목록은 "검사를 면제받은 것"이 아니라 "정본과 맞춰 봤다고 서명한 것"이다.
완료 보고에는 정본 파일 경로와 대조한 값(최소 배경·글자·표 헤더 3색)을 적는다.

> **실제 사고**: 통합재고관리 이관(2026-07-23)에서 정본의 라이트 slate 팔레트(`#f1f5f9` 배경·흰 카드·`#0f172a` 헤더)를
> ERP 공용 다크 팔레트로 새로 썼고, CSS 머리 주석에는 "원본 팔레트를 보존"이라고 **사실과 반대로** 적어 리뷰에서도 안 걸렸다.
