# store-tab — 기본 제외 목록·남길 것 (§1 · §2)

> 본체 `SKILL.md` 에서 분리. 매장탭 범위를 정할 때에 읽는다.

## 1. 기본 제외 목록 (요청자가 범위를 지정하지 않았을 때의 기본값)

> **이 표는 상한이 아니라 출발점이다.** 요청자가 "이 영역은 원본 그대로 두라"고 하면 그 지정이 이긴다.
> 표를 근거로 요청자가 남기라고 한 것을 빼지 않는다.

| # | 제외 대상 | 원본 탭의 실제 예 | 사유 |
|---|---|---|---|
| E1 | **상단 탭간이동 버튼(서브탭 바)** | `SubTabLayout` 의 `.subtab-bar-content` | 매장은 본사 탭 사이를 오갈 일이 없다. **라우트를 `SubTabLayout` 없이 등록**해 원천 차단(§3-2) |
| E2 | **페이지 헤더(제목·부제)** | `.page-header` | 사이드바에 이미 있다. 세로 공간 낭비 |
| E3 | **매장간 비교 테이블** | 샘플반납 매장간 비교표 · 지급율 매장별 지급율 표 · 통합재고 매장별 요약 | 타 매장 실적 노출. 비교 판단의 주체는 본사다 |
| E4 | **전사 합계·집계 컬럼** | 전매장 KPI 카드 · 합계행 · 누적/평균 · 보유매장수 · 매장수 | 본사 의사결정용 지표 |
| E5 | **판정 파라미터 상수 표** | 로직표 · 가중치 · 임계 상수 목록 | 매장이 조정할 대상이 아니다. (score·경과일처럼 **매장이 이미 보고 일해 온 값은 남긴다**) |
| E6 | **시뮬레이션·정책 파라미터 조정** | 반납 시뮬 박스(기한·점수 컷오프) · 안전재고 설정 · 기간/가중치 입력 | 본사 정책. 매장이 바꾸면 정본이 흔들린다 |
| E7 | **생성·재계산·배치 트리거** | 주문장 생성 · 풀 재계산 · 캐시 클리어 · 배치 재실행 | 운영 사고 경로. 매장 화면에 두지 않는다 |
| E8 | **운영/디버그 표시** | 데이터 상태 · 빌드 이력 · stale 경고 배너 · raw JSON · 커버리지/원천점검 | 본사·개발 관측용 |
| E9 | **대량 편집·전송 워크플로** | 워크북 시트 편집 · 마스터시트 전송 · 다중선택 이동/복사 | 본사 워크플로 전체가 딸려온다 |
| E10 | **차트·추이 그래프** | 주별 지급 추이 · 월별 시계열 | 액션으로 이어지지 않으면 장식이다 |
> 위 항목을 **넣어야 할 사유**가 있으면 plan 에 적고 승인받는다. 조용히 포함하지 않는다.
> 반대로 요청자가 남기라고 한 것을 이 표를 근거로 빼지도 않는다.

## 2. 남길 것 (판단 기준)

- **매장이 오늘 할 일** — 대상 행과 그 **사유**. 사유는 결론이 드러나게 표기한다.
- **상품 식별에 필요한 것** — 이미지 · 품명 · 컬러/사이즈 · 현재고 · 최근 판매.
- **매장이 실제로 수행하는 액션** — 체크/저장·엑셀 등. 매장이 하지 않는 본사 액션만 뺀다.
- **검색·정렬** — 목록이 길면 남긴다.

**규모**: 고정 상한을 두지 않는다. 다만 **원본보다 단순해야** 한다 —
plan 에 **원본 대비 무엇이 줄었는지**(서브탭·컬럼·버튼 수)를 적어 확인받는다.
요청자가 "원본 그대로"라고 한 영역은 컬럼 수와 무관하게 그대로 둔다.
